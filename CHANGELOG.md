# Changelog

## 1.0.0 prepared revision source

Target clipping now follows the manuscript order: clip the reference, then compute and clip the state error. Canonical results and Figure 1 have been regenerated. Gate-only and decay-only ablations, six-parameter OAT sweeps, and five-topology initial-condition trials are included. The package adds modular model source, analytic tests, exact environment/seed records, metadata validators. Source and numerical outputs are ordinary repository files.

The corrected canonical partial-stress endpoint reduction is 15.70%; the earlier implementation gave 16.56% (approximately 17%). Zero-disturbance canonical values remain unchanged to reported precision. The publication and release status is pre-publication; no new public GitHub tag is asserted by this snapshot.
